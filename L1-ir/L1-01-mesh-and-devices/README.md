# L1-01 · `mesh-and-devices` — 逻辑网格与设备编号

> 层：**L1 · IR 构件** ｜ 优先级：P0 ｜ 前置课：`intro/`（预备篇）

## 学习目标

看完这一课，你应该能：

1. 说出 `sdy.mesh` 三个组成部分（符号名 / 轴列表 / 可选设备编号）各自的作用；
2. 区分四种网格形态：空网格、maximal-sharding、带轴+隐式编号、带轴+显式编号；
3. 由 `device_ids` 反推某个逻辑位置（如 `a=1`）落在哪台设备上；
4. 解释**为什么显式写的 `device_ids=[0,1,2,3]` 打印时会消失**；
5. 看到任一非法 `sdy.mesh` 时说出违反哪一条约束。

## 核心结论

- **设备总数 = ∏ 轴大小**，必须与 `device_ids` 个数一致。
- `device_ids` 的语义是「**逻辑位置 i → 设备号**」，不是设备号列表本身。
- `device_ids` 排序后必须恰好是 `[0, 1, …, n-1]`（不重复、不越界、不缺号）。
- 当 `device_ids` 恰好等于 `iota(∏轴大小)` 时，**必须省略**，打印时会被去掉。
- 空网格 `<[]>` 是占位符；`<[], device_ids=[k]>` 是 maximal-sharding 网格（单设备）。
