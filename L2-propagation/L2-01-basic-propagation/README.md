# L2-01 · `basic-propagation` — 基础传播

> 层：**L2 · 传播算法**（开篇） ｜ 优先级：P0 ｜ 前置课：`L1-03`、`L1-05`

## 学习目标

看完这一课，你应该能：

1. 描述传播是「沿数据流迭代到不动点」的过程；
2. 解释为什么传播结果里会多出 `?`（开维标记），以及它与闭维的关系；
3. 判断两个分片能否传播（**最长兼容主分片轴**）；
4. 说出 reshape 为什么沿**因子**而不是维度传播；
5. 说出「完整轴 → 子轴」为什么可以、反过来为什么不行；
6. 说出不可整除在传播阶段**不是错误**；
7. 说出跨网格不传播、以及那个例外（同名内容相同的网格会传播）；
8. 说出空网格与 maximal 网格在传播中的特殊规则。

## 核心结论

- **基础传播最保守**：只传「所有操作数与结果都同意」的轴，**绝不消解冲突**。
- 传播加上的分片默认**开放**（带 `?`）；闭维是**用户**锁的，两者可以共存（`{"b", ?}`）。
- 冲突时取**最长兼容主分片轴**：从 major 逐位比，遇到不一致就停；完全不一致则一个都不传。
- 传播在**因子**层面进行：reshape 能零通信，正是因为被切的因子在合并后仍是最高位。
- **完整轴 → 子轴**可传播，反向不行。
- **不可整除不是错误**；padding 是导出阶段的事（L5-09）。
- 分片只在**同一网格**内传播；网格名不同但轴与设备序相同时例外。
- 空网格可被填充（闭维除外）；maximal 网格不替换、也不沿它传播。
