## 核心结论

- 用户优先级是**最外层**：对每个优先级 `p`，完整跑一遍**算子优先级传播**。
- **逐维比较**：结果可能"第 0 维听你的、第 1 维听我的"。
- **允许跳号**：`p0` 与 `p4` 可以共存，中间缺失不影响语义。
- 高优先级（数字小）赢；但**用户标注不会被删除**，只是不向外传播。
- 高优先级可以在低优先级的**开维**上继续加轴（轴序保持，只是变长）。
- `{?}pN` 合法（"轮到 pN 时可切"）；`{}pN` 非法（没有可排序的切分决策）。
