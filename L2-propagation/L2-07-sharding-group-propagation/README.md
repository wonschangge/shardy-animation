# L2-07 · `sharding-group-propagation` — 分片组传播

> 层：**L2 · 传播算法** ｜ 优先级：P1 ｜ 前置课：`L1-09`、`L2-06`

## 学习目标

看完这一课，你应该能：

1. 说出分片组是传播里的**第二条通道**（绕开数据流）；
2. 说明组为什么能**穿透传播屏障**（这是它"独立通道"身份的最强证据）；
3. 说出组内冲突的**裁决规则**（用户优先级）；
4. 说出完全不兼容时传播的行为（**插入额外约束**，而不是放弃）；
5. 说出组内已有分片如何影响其余成员。

## 场景（6 幕）

1. 分片组：传播里的第二条通道
2. 最强例证：组能穿透传播屏障
3. 组内冲突按用户优先级裁决
4. 完全不兼容时自动插入约束
5. 两个补充：已有分片直接赋值、跨数据流边
6. 练习

## 核心结论

- 分片组是**独立通道**：不依赖数据流，也不受传播屏障限制。
- 组内冲突的裁决规则与 L2-06 一致：**用户优先级高的赢**。组本身不引入新规则。
- 完全不兼容时传播**插入 `sdy.sharding_constraint`** 统一两者，并把组重建到新约束上。
- 组内已有分片会**直接赋给**其余成员。
- 时机：**先做组 id 的合并与规范化，再做兼容性检查**（L3-09 讲合并，本课讲传播行为）。
