# L2-04 · `aggressive-propagation` — 激进传播

> 层：**L2 · 传播算法** ｜ 优先级：P0 ｜ 前置课：`L2-01`、`L1-05`

## 学习目标

看完这一课，你应该能：

1. 说出激进传播比基础传播**多做**什么、以及它**不做**什么；
2. 区分**假冲突**（同一轴落在不同因子）与**真冲突**（同一因子上不同轴）；
3. 解释"侧向传播"是什么、什么时候触发；
4. 说出「优先选分片最多的一侧」这条启发式的动机与代价；
5. 解释未归约轴为什么阻断反向传播、却不妨碍前向。

## 场景（8 幕）

1. 激进传播的定位（能做什么 / 不能做什么）
2. 无冲突时与基础传播逐字相同
3. 假冲突：同一个轴，不同因子
4. 真冲突：同一因子上两个不同的轴 → **不消解**
5. 侧向传播：结果被锁死时走操作数之间
6. 启发式：优先选分片最多的一侧
7. 未归约轴阻断反向传播
8. 练习

## 核心结论

- 激进传播 = 基础传播 **+ 一组消解规则**；没触发规则时两者输出完全相同。
- **冲突要看因子，不是看轴名**：
  - 同一轴落在**不同因子** → 假冲突，两者都保留；
  - 同一因子上出现**两个不同轴** → 真冲突。
- **激进 ≠ 消解一切冲突**：两边都是用户标注且互不相容时，它**不猜**，结果上直接没有分片。
- **侧向传播**：结果被显式锁死时，改为在操作数之间横向同步（6 个测试用例覆盖各种锁法）。
- **启发式**：需要选边时优先「分片更多」的一侧 —— 分得越细，每台设备数据越少
  （代价是可能多出通信）。
- **未归约轴**（`unreduced={...}`）阻断**反向**传播，但前向照常。
