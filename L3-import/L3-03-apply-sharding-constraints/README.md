## 核心结论

- **下沉**：把约束的分片直接写到操作数上，约束算子消失 —— 传播时少一层间接。
- **三个条件**（必须同时满足）：
  1. 操作数**没有**自己的分片标注（否则会覆盖用户语义）
  2. 约束必须是**闭维**的（开维是"下界"，下沉会过度约束）
  3. 操作数**没有其它不同的**约束使用者（相同的可以）
- **两类反直觉边界**（都**下沉**）：
  - 有其它**普通**使用者 → 不影响（普通使用者由传播协调）
  - 约束**悬空** → 照样下沉（悬空约束表达的正是"操作数本身该怎么切"）
- **约束链**：只下沉**链头**；链尾的操作数是约束 → 不下沉。
  两条约束算子**都保留**（下沉是"抄一份"，不是删除）。
- **`preinlined` 版本**：函数调用边界会挡住下沉分析，所以先 `-sdy-import-func-calls`
  内联成 `sdy.named_computation`，再应用约束。
