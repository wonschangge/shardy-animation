## 核心结论

- **假依赖**：一个常量被多处使用 → 这些使用方**被迫统一分片**，哪怕数据上毫无关系。
- **核心规则**：N 个**使用**（不是使用者）→ 复制 N 份，每份独立分片。
  - 同一个算子用了两次（`dot_general %0, %0`）**照样拆**。
  - `stablehlo.constant` 会被换成 `sdy.constant`。
- **三种不拆**（统一判据：复制后能否获得**分片自由度**）：
  - 单使用者 → 无假依赖
  - 标量（rank-0）→ 没有维度可分片
  - 非标量输入的 broadcast → 不套用标量规则
- **标量 broadcast**：复制的是 **broadcast 算子**，因为标量不可分片、但 broadcast 结果可分片。
  这就是文件名 `constant_<b>or_scalar</b>_splitter` 的由来。
- **与 L1-10 呼应**：`sdy.constant` 不带 folder，复制出来的多份才不会被合并回去。
