## 核心结论

- **这个 pass 做两件事**：**提升**（内联 → 顶层声明 + 起名）与 **去重**（内容相同则合并）。
- **为什么要提升**：内联定义没有名字，无法被别处引用；有了名字才能判断"是否同一个网格"。
- **命名规则**：
  | 内联定义 | 名字 |
  |---|---|
  | `mesh<["x"=2, "y"=2]>` | `@mesh_0`（基础名 + 编号，**避开已占用的名字**） |
  | `mesh<[]>` | `@empty_mesh`（固定名） |
  | `mesh<[], device_ids=[N]>` | `@maximal_mesh_N`（**设备号进名字**） |
- **命名只看名字是否被占用**，与内容像不像**无关**（轴名不同也会编号成 `@mesh_0`）。
- **去重判据是内容**（轴名、大小、设备序），与名字无关；多余的声明被删除、引用被改写。
- `device_ids` 不同的 maximal 网格**不会**被去重 —— 它们语义上就是不同网格。
- **覆盖范围**：8 类位置（SDY 算子分片 / `manual_computation` / 函数调用 / `all_reduce` /
  调用结果 / 非扁平调用图 / 归约算子 / tagged mesh 属性）。
