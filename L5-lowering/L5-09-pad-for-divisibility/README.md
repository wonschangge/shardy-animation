## 核心结论

### 两种方向

| 方向 | 解法 |
|---|---|
| **输入不可整除** | **`pad` 补齐** → 通信 → `slice` 裁回 |
| **输出不可整除** | `slice` 到**可整除** → 通信 → `slice` 裁到目标 |

**统一模式**：**让通信发生在「可整除的形状」上**。

### 具体例子

**输出不可整除**：源 IR 写 `[0:3]`，但 3 不能被 `x=4` 整除
→ 导出时改成 `[0:4]`，`all_gather` 参数从 `tensor<3x8>` 变成 **`tensor<4x8>`**，
通信后再 `slice` 裁到 3。

**输入不可整除**：`4x7` 的第 1 维 7 不能被 `y=2` 整除
→ `pad low = [0, 0], high = [0, 1]` 补成 **`4x8`**，
通信后再 `slice` 裁到目标。

### padding 值的选择

12 个文件里 padding 值**都是零**（`dense<0.000000e+00>` × 56、`dense<0>` × 14）。

**为什么可以填 0**：通信是**数据搬运**（不涉及算术），
且补的部分随后**被 `slice` 裁掉** → 根本不会出现在最终结果里。

**★ 但如果通信后紧跟归约**，填的值**必须不影响归约结果**：
| 运算 | 填 0 是否安全 |
|---|---|
| `sum` | ✓（加法单位元） |
| `max` | ✗ 数据全为负时 0 会变成最大值 |
| `min` | ✗ 数据全为正时 0 会变成最小值 |
| `mul` | ✗ 会把结果变成 0 → 必须填 **1** |

**核心原则**：padding 值必须是该运算的**单位元**（或不影响结果的值）。

### ★ 验收点答案

> 给定 `tensor<7x3x8>` 沿 `z=3` 分片：
> - 若沿**第 2 维**（大小 8）分片：`8` 不能被 `3` 整除
>   → 补到下一个 3 的倍数 = **9**
>   → **`pad low = [0, 0, 0], high = [0, 0, 1]`**，补齐后形状 **`7x3x9`**
> - 通信后 `slice` 裁回 `7x3x8`

## L5 收官：三条核心规律

1. **只有归约方向上的分片需要通信**（L5-05～08）
2. **位置相关的算子要补偿位置**（L5-04 的 iota、L5-08 的索引重映射）
3. **不可整除时让通信发生在可整除的形状上**（本课）
